What's New

Every feature, improvement, and fix across all versions of TouchLock.

v1.2.0 Latest September 2026

Flexible PIN length, keyboard shortcuts, and quality-of-life improvements.

Flexible PIN Length (4–10 digits)

Choose anywhere from 4 to 10 digits for your PIN. A live strength indicator shows Weak, Fair, Good, or Strong as you type.

Keyboard Shortcut to Lock

Instantly lock the browser with Alt+L (or Ctrl+L on Mac). Fully customizable from Settings — reserved browser shortcuts are blocked with clear warnings.

Firefox Auto-Shortcut Sync

On Firefox, custom shortcuts are automatically applied at the browser level via browser.commands.update() — no manual step needed.

What's New Notifications

After updates, a subtle notification dot in Settings lets you discover new features without any interruption.

v1.1.0 August 2026

First public release with full browser locking, biometrics, and recovery.

Biometric Unlock

Unlock with Touch ID on Mac or Windows Hello on PC. Auto-triggers when the lock screen loads — no clicks needed.

Profile-Level Lock

Blocks access to the entire browser profile — history, downloads, bookmarks, passwords — until you authenticate.

6-Digit PIN with SHA-256

Secure fallback PIN hashed with SHA-256 and random salt. Never stored in plaintext.

Tab Guards

Five layers of protection prevent switching tabs, opening new tabs, or closing the lock tab while locked.

Auto-Lock on Startup & Idle

Locks automatically on browser launch. Optional idle lock after configurable inactivity (1 min – 1 hour).

PIN Recovery via Security Questions

Set 3 security questions during setup. Answer any 2 correctly to reset a forgotten PIN.

v1.0.0 July 2026

Internal release. Foundation for Manifest V3 architecture and core locking mechanism.

Initial Build

Core service worker, lock screen, content overlay, and extension popup. Manifest V3 architecture for Chrome 110+ and Edge 110+.
