    Lock screen

    Fullscreen lock screen Hides the address bar, tabs, and browser UI on the lock screen. Only applies when you switch to the browser, so it won't interrupt other apps. On some computers, fullscreen can make the browser freeze or stop responding. If that happens, turn this off.
